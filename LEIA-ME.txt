EMBRIOGESTOR - MODO OFFLINE v2
===============================

Esta versão corrige a abertura SEM INTERNET no celular.

ARQUIVOS
- sw.js
- offline-register.js
- offline-mode.js

INSTALAÇÃO
1. Substitua o sw.js atual pelo deste pacote.
2. Substitua offline-mode.js pelo deste pacote.
3. Envie offline-register.js para a raiz do repositório.

4. No index.html, perto do final, deixe esta ordem:

   <script src="cloud.js?v=40"></script>
   <script src="offline-mode.js?v=2"></script>
   <script src="offline-register.js?v=2"></script>

   Os outros scripts podem continuar normalmente.

5. Commit changes.

PRIMEIRA INSTALAÇÃO NO CELULAR (OBRIGATÓRIA)
1. Conecte o celular à internet.
2. Abra o EmbrioGestor pelo endereço do GitHub Pages.
3. Faça login.
4. Deixe a página aberta por 15-30 segundos.
5. Atualize a página uma vez.
6. Feche COMPLETAMENTE a aba/app.
7. Abra novamente ainda com internet.
8. Agora desligue Wi-Fi e dados móveis.
9. Feche e abra de novo o EmbrioGestor.

A partir daí o aplicativo deve abrir offline.

IMPORTANTE
- Um aparelho que NUNCA abriu essa versão enquanto estava online não consegue funcionar offline.
- O Google Drive só sincroniza quando a internet voltar.
- Os dados lançados offline continuam no armazenamento local do aparelho.
- Não trabalhe simultaneamente em dois aparelhos com alterações pendentes, porque a sincronização atual é por arquivo principal.

SE FOR INSTALADO COMO PWA
Depois que o modo offline estiver instalado, usar "Adicionar à tela inicial" melhora a experiência.
