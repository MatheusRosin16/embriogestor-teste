EMBRIOGESTOR — OPU -> PRODUÇÃO AUTOMÁTICA v1

O QUE FAZ

Sempre que uma Aspiração de Oócitos for salva:

1. O sistema considera a "pasta" da OPU como:
   CLIENTE + DATA DA ASPIRAÇÃO

2. Para cada doadora aspirada naquele Cliente/Data, cria automaticamente
   uma Produção de Embriões.

3. A Produção já nasce com:
   - Data
   - Cliente
   - Doadora
   - Raça da doadora
   - Oócitos totais = G1 + G2 + G3 + G4
   - Oócitos viáveis = G1 + G2 + G3

4. Os demais dados ficam livres para completar depois:
   - Touro
   - Clivados
   - Embriões D7
   - Transferidos
   - Congelados DT
   - Congelados VT
   - e demais campos da Produção

IMPORTANTE
- Não cria a mesma produção duas vezes.
- Se já existir uma produção com o mesmo Cliente + Data + Doadora,
  ela é aproveitada em vez de duplicada.
- Ao editar a OPU, Data/Cliente/Doadora/Oócitos da produção são atualizados.
- Touro, clivados, D7 e outros dados digitados manualmente NÃO são apagados.
- Ao instalar, ele também verifica as OPUs antigas e cria somente as
  produções que estiverem faltando.

A "pasta" é registrada no banco como grupo Cliente + Data, usando:
- grupoAspiracaoChave
- grupoAspiracaoNome

Como o EmbrioGestor atual já agrupa produções por cliente/data,
essas produções entram juntas no mesmo grupo visual.

============================================================
INSTALAÇÃO
============================================================

1. Envie para a raiz do GitHub:
   opu-producao-automatica.js

2. No index.html, coloque DEPOIS de app.js.

Pode ficar perto dos outros módulos:

<script src="app.js?v=40"></script>
...
<script src="opu-producao-automatica.js?v=1"></script>

Se estiver usando cloud.js, pode colocar depois dele também:

<script src="app.js?v=40"></script>
<script src="cloud.js?v=40"></script>
<script src="opu-producao-automatica.js?v=1"></script>

3. No sw.js, dentro de ESSENCIAIS, adicione:

"./opu-producao-automatica.js",

4. Aumente o número do CACHE em 1.

5. Faça Commit.

6. Abra o EmbrioGestor com internet e atualize uma vez.
